# Sneaky Dog: Park Escape

Прототип мобильной игры: собака пытается незаметно сделать своё дело на клумбе, которую стережёт садовник, и уйти через выход.

Сейчас это играбельный 3D-прототип (Three.js, без сборки) для проверки геймплея на телефоне. Финальная версия планируется как мобильное приложение. Старая 2D-версия заморожена (0.1.9) и лежит в `2d/`.

Как играть на iPhone: откройте ссылку GitHub Pages в Safari → «Поделиться» → «На экран „Домой“». С иконки игра запускается на весь экран.

Управление на телефоне: джойстик слева (слабо — красться, сильно — бег), справа мяч 🎾 и «💩» (удерживать); пальцем по экрану — повернуть и наклонить камеру, двумя — приблизить.
