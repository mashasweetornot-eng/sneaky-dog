# Sneaky Dog: Park Escape

Прототип мобильной игры: собака пытается незаметно сделать своё дело на клумбе, которую стережёт садовник.

Сейчас это играбельный 2D-прототип (HTML/Canvas, версия 0.1.5) для проверки геймплея на телефоне. Финальная версия планируется как мобильное приложение.

Как играть на iPhone: откройте ссылку GitHub Pages в Safari → «Поделиться» → «На экран „Домой“». С иконки игра запускается на весь экран.

Управление на телефоне: джойстик слева, способность и «💩» справа.
