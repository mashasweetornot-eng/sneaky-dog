# Sneaky Dog: Park Escape — инструкции для Claude Code

Мобильная стелс-игра: собака должна незаметно сделать «дело» на клумбе, которую стережёт садовник, и вернуться к воротам. Сейчас это играбельный 2D-прототип на HTML/Canvas для проверки геймплея на iPhone. Финальная платформа (нативное приложение, движок, 3D) ещё не выбрана — без согласия владельца не переходить.

## Как мы работаем

- Владелец общается по-русски. Коммиты, комментарии к задачам и ответы — по-русски.
- Идеи обсуждаются с Claude в чате (Cowork), решения записываются в `TASKS.md`. Ты (Claude Code) берёшь задачи оттуда, делаешь, коммитишь в `main` и отмечаешь задачу в `TASKS.md` (статус + короткая заметка, что сделано и что проверить).
- Не меняй задачи/решения в `TASKS.md` по своей инициативе — только статус и заметки. Новые идеи добавляй в раздел «Предложения».
- Каждое изменение выкладывается сразу: push в `main` → GitHub Pages обновляется за ~1 мин.
- Живой адрес: https://mashasweetornot-eng.github.io/sneaky-dog/ (владелец играет с иконки на экране «Домой» iPhone, часто в горизонтальной ориентации).

## Устройство проекта

- `index.html` — вся игра (CSS + JS внутри, без библиотек и сборки). Canvas 2D для мира, DOM для интерфейса.
- `3d/index.html` — 3D-прототип (этап 3D-0): Three.js с CDN, логика перенесена из 2D, камера сзади-сверху, расстояние в длинах корпуса породы (k × len): один палец — поворот и наклон, два — зум, «Запомнить камеру» в ⚙; игровые правила камеру не читают; породы в BREEDS с габаритами len/hgt; скорости в м/с, замеры парка во времени в ⚙. Отладка: `window.SneakyDog3D.snapshot()`, версия `3D-0.x` (поднимай при изменениях 3D).
- `hero.jpg` — картинка меню. `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` — режим «приложения» на телефоне.
- Сохранение: `localStorage['sneaky-dog-v1']` = `{unlocked, best}`.
- Отладка: `window.SneakyDog.snapshot()` и `window.SneakyDog.version`.

Ключевые части кода: `dogs`, `levelData`, `routeFor(i)` (расписание садовника), `makeMap()`, `blocked()/lineClear()/travel()`, `findPath()` (A*), `menu()/begin()/pause()/finish()`, `ability()`, `update(dt)`, `draw()`, `resize()`, `loop()`.

## Правила

- **Игра мобильная.** Всё, что касается удобства и эргономики управления, решается и проверяется на телефоне (пальцем, в том числе в горизонтали). Клавиатура — только вход для автотестов: на её удобство время не тратим, новые клавиши под эргономику не придумываем.
- При каждом изменении поднимай версию в двух местах: `Прототип 0.1.x` (меню) и `version:'0.1.x'`.
- Перед коммитом: проверка синтаксиса JS и запуск в браузере без ошибок консоли. Желательно автотест через Playwright (`window.SneakyDog.snapshot()` даёт состояние).
- Учитывай телефон: портрет и горизонталь (`screenH < 560`), безопасные отступы, мультитач (кнопки на `pointerdown`), полноэкранный режим с иконки.
- Не ломай работающий цикл: изучить маршрут → спрятаться → выбрать момент → сделать дело → вернуться к воротам.

## Текущий геймплей (0.1.7)

- Садовник охраняет клумбу: работает у неё (💧), делает обходы (👀), уходит по делам к крану 🚰 / тачке 🧺 — это окно для собаки. После отвлечения возвращается к клумбе.
- Заметив собаку, садовник останавливается и смотрит; потерял — идёт проверить место; увидел снова — погоня (скорость ×1.58).
- Если садовник увидит «сюрприз» на клумбе до ухода собаки — ярость (скорость ×1.2, зрение ×1.15) и бег к воротам.
- Породы: Лабрадор (мяч), Джек-рассел (рывок), Корги (тихий шаг, заметность ×0.68). 3 уровня.
- Управление: ПК — WASD, Shift бег, C красться, E способность, пробел держать, Esc пауза. Телефон — джойстик, способность, 💩 (удерживать).

Полная история изменений и детали — в `HANDOFF.md` (если есть) и в истории коммитов.
